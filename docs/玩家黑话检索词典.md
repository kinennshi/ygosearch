# 玩家黑话检索词典

先把黑话展开为卡片原文可验证的条件，再检索。不要把相关但不等价的效果混为一类。

## 严格效果映射

| 黑话 | 检索含义 |
|---|---|
| 康 | 默认优先召回发动无效、效果无效；广义妨害只能另列 |
| 擦 | 仅效果无效，且不附带破坏、除外、送墓、解放、回手或回卡组 |
| 全抗 | 不受效果影响或语义等价描述 |
| 威风抗性 | 同时具有效果破坏抗性与取对象抗性 |
| 抗性 | 效果破坏抗性、取对象抗性、不受效果影响等上位概念 |
| 耐性 | 默认指战斗破坏抗性 |
| 代破 | 以其他处理代替本应发生的破坏 |
| 贯通/穿防 | 攻击守备表示怪兽时造成超过守备力的战斗伤害 |
| 幻层效果 | 战斗期间限制对方发动魔法、陷阱、怪兽效果 |
| 炸 | 破坏 |
| 弹 | 场上的卡回到手牌或卡组 |
| 洗 | 回到卡组；涉及随机次序时也可能指洗牌 |
| 苏 | 从墓地特殊召唤怪兽 |
| 跳/叫/拉/带 | 特殊召唤，需结合来源区域判断 |
| 风 | 破坏或处理魔法、陷阱的卡/效果 |
| 坑 | 能妨害对手的陷阱 |
| 手坑/素质 | 能从手牌发动并妨害对手的卡，通常指怪兽 |
| 贴纸 | 持续留场并限制行动的永续陷阱；广义含永续魔法、场地魔法 |
| 妨害 | 破坏、除外、无效、禁止操作等阻碍对手行动的上位概念 |
| 除去 | 让场上的卡离场，不限破坏方式 |
| AOE | 同时处理多张卡的大范围除去 |
| 检索 | 从卡组把指定卡加入手牌 |
| 滤抽/过牌 | 抽牌或用手牌交换改善手牌质量 |
| 回收 | 从墓地或除外状态回到手牌或卡组 |
| 堆墓 | 主动把自己的有用卡送去墓地 |
| 烧/烫血 | 造成效果伤害 |
| 削手/手札破坏 | 减少对方手牌 |
| 自肃 | 效果使用后限制玩家自己的操作 |

## 卡片类型与数值简称

- 凡骨/白板＝通常怪兽；紫怪＝融合怪兽；白怪＝同调怪兽；黑怪＝超量怪兽。
- P怪＝灵摆怪兽；LINK怪/lin怪＝连接怪兽；Token/毛＝衍生物。
- L通常表示等级，R表示阶级，LINK3表示连接值3。
- ATK/打点＝攻击力；DEF/屁股＝守备力。

## 阶段与区域简称

- DP抽卡阶段；SP/准阶为准备阶段；M1/M2为主要阶段1/2；BP/战阶为战斗阶段；EP为结束阶段。
- 攻宣＝攻击宣言；伤判＝伤害判定步骤；T1＝第一回合。
- deck/dei＝卡组；手札/手/han＝手牌；墓＝墓地；P区＝灵摆区域。
- 前场＝怪兽区域；后场＝魔法与陷阱区域；盖＝里侧表示。

## 构筑与对局语境

- FTK＝第一回合获胜；OTK＝一个回合内将对方基本分打到0。
- 初动＝第一波展开；续航＝消耗后继续运转；终端＝展开最后形成的压制卡；跳板＝制作终端的中间素材。
- 大哥/大姐＝主题中攻击力或效果最强的核心怪兽，不是规则字段。
- 本家/字段＝卡名或系统归属；泛用＝可用于许多卡组；针对＝专门克制特定对象。
- 卡手、废件、上限、下限、稳定性都依赖构筑和环境，不能只靠单卡文本机械断定。
