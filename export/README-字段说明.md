# 卡片数据库导出说明

> 数据源：`cdb/{zh-CN,en-US,ja-JP}/cards.cdb`（SQLite）
> 导出脚本：`export_cards.py`
> 导出时间：2026-09-29

---

## 一、导出了什么

每种语言导出 **4 个文件**，按用途选：

| 文件 | 用途 | 特点 |
|---|---|---|
| `cards_<lang>.csv` | **给程序读** | 原始字段，位掩码保持数值，UTF-8 BOM |
| `cards_<lang>.readable.csv` | **给人看 / Excel 打开** | 位掩码已译成中文（类型/种族/属性/系列） |
| `cards_<lang>.json` | **给程序读（结构化）** | 同时含原始数值与解码后字段 |
| `cards_<lang>.md` | **直接浏览** | 按怪兽/魔法/陷阱分组，含卡名、属性、效果全文 |

当前规模（每种语言均为 15,019 张）：

| 语言 | 原始 CSV | 可读 CSV | JSON | Markdown |
|---|---|---|---|---|
| zh-CN | 5.4 MB | 6.2 MB | 12.3 MB | 6.6 MB |
| en-US | 5.4 MB | 6.2 MB | 12.2 MB | 6.5 MB |
| ja-JP | 7.6 MB | 8.4 MB | 14.5 MB | 8.9 MB |

三种语言的卡牌 ID **完全一一对应**，可放心用 `id` 关联。

## 二、原始数据库结构

`cards.cdb` 是 SQLite，两张表：

### datas — 数值字段

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER | 卡片唯一 ID（主键），8 位数字，跨语言一致 |
| `ot` | INTEGER | 卡池归属，见下方对照 |
| `alias` | INTEGER | 别名。非 0 时表示这张卡的「真名」是另一个 id |
| `setcode` | INTEGER | 系列码，**可打包多个系列**，每 16 位一个 |
| `type` | INTEGER | **类型位掩码**，见下方完整拆解 |
| `atk` | INTEGER | 攻击力，`-2` 表示 `?` |
| `def` | INTEGER | 守备力，`-2` 表示 `?`；**连接怪兽此列存的是链接箭头位图** |
| `level` | INTEGER | **多义打包字段**，见下方拆解 |
| `race` | INTEGER | **种族位掩码**（64 位，可多选） |
| `attribute` | INTEGER | **属性位掩码**（通常单选） |
| `category` | INTEGER | 效果类别位掩码，用于筛选"破坏/检索/特殊召唤"等效果类型 |

### texts — 文本字段

| 列 | 说明 |
|---|---|
| `id` | 外键，对应 datas.id |
| `name` | 卡名 |
| `desc` | 效果文本 / 描述 |
| `str1`~`str16` | 预留的附加文本槽（多数卡片为空） |

## 三、位掩码拆解（关键）

### type — 卡片类型

低 3 位决定大类，其余位是叠加的能力标签。

**大类**

| 值 | 含义 |
|---|---|
| `0x1` | 怪兽 |
| `0x2` | 魔法 |
| `0x4` | 陷阱 |

**怪兽相关**

| 值 | 含义 | 值 | 含义 |
|---|---|---|---|
| `0x10` | 通常 | `0x20` | 效果 |
| `0x40` | 融合 | `0x80` | 仪式 |
| `0x1000` | 调整 | `0x2000` | 同调 |
| `0x800000` | 超量 | `0x1000000` | 灵摆 |
| `0x4000000` | 连接 | `0x4000` | 衍生物 |
| `0x200` | 灵魂 | `0x400` | 同盟 |
| `0x800` | 二重 | `0x100` | 陷阱怪兽 |

**魔法相关**

| 值 | 含义 | 值 | 含义 |
|---|---|---|---|
| `0x10000` | 速攻 | `0x20000` | 永续 |
| `0x40000` | 装备 | `0x80000` | 场地 |

**陷阱相关**

| 值 | 含义 | 值 | 含义 |
|---|---|---|---|
| `0x20000` | 永续 | `0x100000` | 反击 |

**其他**

| 值 | 含义 |
|---|---|
| `0x200000` | 反转 |
| `0x400000` | 卡通 |
| `0x2000000` | 特殊召唤（如"不能通常召唤"） |

> 例：`type = 0x1 | 0x20 | 0x4000000 = 67108897` → 怪兽 + 效果 + 连接

### level — 多义打包字段（最容易踩坑）

`level` 不是单纯的等级，它把三个信息打包进一个整数：

| 位段 | 取值方式 | 含义 |
|---|---|---|
| 低 8 位 | `level & 0xff` | 等级 / 阶级 / 连接等级 |
| 第 16–23 位 | `(level >> 16) & 0xff` | 灵摆 **右刻度** |
| 第 24–31 位 | `level >> 24` | 灵摆 **左刻度** |

- 超量怪兽：低 8 位是**阶级**（Rank）
- 连接怪兽：低 8 位是**连接等级**（LINK 值）
- 灵摆怪兽：另外打包左右刻度，所以 `level` 原始值可能非常大（最大到 2 亿多），**不能当普通整数读**

> 例：真实卡片「DD 魔导贤者 托马斯」的 `level = 101056520`（`0x6060008`）
> → 等级 `0x08` = 8，左刻度 `0x06` = 6，右刻度 `0x06` = 6

### def — 连接怪兽的箭头位图

连接怪兽没有守备力，`def` 列被复用为**链接箭头位图**（`level & 0xff` 是 LINK 值）：

| 值 | 方向 | 值 | 方向 |
|---|---|---|---|
| `0x001` | 左下 | `0x002` | 下 |
| `0x004` | 右下 | `0x008` | 左 |
| `0x020` | 右 | `0x040` | 左上 |
| `0x080` | 上 | `0x100` | 右上 |

> 例：`def = 0x22` → 下 (`0x02`) + 右 (`0x20`)

### race — 种族

| 值 | 种族 | 值 | 种族 | 值 | 种族 |
|---|---|---|---|---|---|
| `0x1` | 战士 | `0x2` | 魔法师 | `0x4` | 天使 |
| `0x8` | 恶魔 | `0x10` | 不死 | `0x20` | 机械 |
| `0x40` | 水族 | `0x80` | 炎族 | `0x100` | 岩石 |
| `0x200` | 鸟兽 | `0x400` | 植物 | `0x800` | 昆虫 |
| `0x1000` | 雷 | `0x2000` | 龙 | `0x4000` | 兽 |
| `0x8000` | 兽战士 | `0x10000` | 恐龙 | `0x20000` | 鱼 |
| `0x40000` | 海龙 | `0x80000` | 爬虫类 | `0x100000` | 念动力 |
| `0x200000` | 幻神兽 | `0x400000` | 创造神 | `0x800000` | 幻龙 |
| `0x1000000` | 电子界 | `0x2000000` | 幻想魔族 | | |

> 注意：`race` 是 **64 位**整数，高位还有 `0x4000000000000000`（妖怪）等值。种族可多选（按位或）。

### attribute — 属性

| 值 | 属性 | 值 | 属性 |
|---|---|---|---|
| `0x01` | 地 | `0x02` | 水 |
| `0x04` | 炎 | `0x08` | 风 |
| `0x10` | 光 | `0x20` | 暗 |
| `0x40` | 神 | | |

### ot — 卡池归属

| 值 | 含义 | 本次数量 |
|---|---|---|
| `11` | 简中 / OCG / TCG 三区通用 | 8,384 |
| `3` | OCG / TCG | 6,186 |
| `1` | 仅 OCG | 233 |
| `9` | 简中 / OCG | 191 |
| `2` | 仅 TCG | 25 |

### setcode — 系列码

一个整数里可打包多个系列，**每 16 位一个**：

- 低 12 位（`& 0xFFF`）＝主系列编号
- 高 4 位（`& 0xF000`）＝子系列编号

拆解方式：不断取 `& 0xFFFF` 然后右移 16 位，直到为 0。系列名对照表在 `cdb/<lang>/strings.conf` 的 `!setname` 段。

> 例：`setcode = 0x1002` → 主系列 `0x002`（次世代），子系列标记 `0x1000`
> （`0x1002` 在 `strings.conf` 里对应"真次世代"）

### atk / def 的特殊值

| 值 | 含义 |
|---|---|
| `-2` | `?`（数值由效果决定，不固定） |
| `0` | 实际就是 0 |

## 四、readable.csv 的列说明

表头为中文，列含义：

| 列名 | 说明 |
|---|---|
| 卡片ID | 对应 `datas.id` |
| 卡名 | 对应 `texts.name` |
| 类型掩码 | `type` 原始数值 |
| 类型 | 解码后的类型标签，用 `/` 连接（如"怪兽/效果/连接"） |
| 主类型 | 怪兽 / 魔法 / 陷阱 |
| 属性掩码 | `attribute` 原始数值 |
| 属性 | 解码后的属性名（地/水/炎/风/光/暗/神） |
| 种族掩码 | `race` 原始数值 |
| 种族 | 解码后的种族名（可多个） |
| 等级原始值 | `level` 原始打包值 |
| 等级 | 拆出的等级/阶级/LINK 值 |
| 灵摆左刻度 | `level >> 24` |
| 灵摆右刻度 | `(level >> 16) & 0xff` |
| 连接标记 | 连接怪兽的箭头方向，用 `/` 连接 |
| 攻击力 | 原始值，`-2` 表示 `?` |
| 守备力 | 原始值，`-2` 表示 `?`；连接怪兽为空 |
| 卡池 | `ot` 原始数值 |
| 卡池说明 | 解码后的卡池名 |
| 别名 | `alias` 原始数值 |
| 系列码 | `setcode` 原始数值 |
| 所属系列 | 解码后的系列名，用 `/` 连接 |
| 效果类别掩码 | `category` 原始数值 |
| 效果文本 | `texts.desc` 全文（含换行，CSV 中已正确转义） |

## 五、JSON 字段逐条说明

`cards_<lang>.json` 中**每一条记录都固定有这 25 个字段**（三语言 45,057 条全量校验过，无例外）。
字段在，但值是否有效取决于卡的类型，下表"有效占比"指该字段非空/非零的卡片比例。

### 身份与分类（所有卡都有值）

| 字段 | 类型 | 作用 | 有效占比 |
|---|---|---|---|
| `id` | int | 卡片唯一 ID。8 位数字，三语言通用，是关联三份 JSON 的主键 | 100% |
| `name` | str | 卡名（当前语言的） | 100% |
| `type` | int | 类型位掩码原始值。程序筛选用，见第三章对照表 | 100% |
| `type_text` | str | 类型解码后的中文，`/` 分隔。如"怪兽/效果/连接" | 100% |
| `type_text_en` | str | 类型解码后的英文。如"Monster/Effect/Link" | 100% |
| `card_kind` | str | 主类型，只可能是 `怪兽` / `魔法` / `陷阱` / `未知` 四值之一。**分流判断用这个** | 100% |
| `ot` | int | 卡池归属原始值（1/2/3/4/8/9/11） | 100% |
| `ot_text` | str | 卡池中文说明。如"简中/OCG/TCG" | 100% |

### 怪兽专属字段（魔法/陷阱为 0 或空）

| 字段 | 类型 | 作用 | 有效占比 |
|---|---|---|---|
| `attribute` | int | 属性位掩码原始值（0x01地 0x02水 0x04炎 0x08风 0x10光 0x20暗 0x40神） | 66%（只有怪兽有） |
| `attribute_text` | str | 属性中文名。魔法/陷阱为空字符串 | 66% |
| `race` | int | 种族位掩码原始值（64 位，可多选） | 66% |
| `race_text` | str | 种族中文名，可多个用 `/` 分隔。如"战士/效果" | 66% |
| `level` | int | **原始打包值**（等级+灵摆刻度），别直接用，用 `level_decoded` | 66% |
| `level_decoded` | int | 拆解后的等级。普通怪兽=等级，超量=阶级，连接=LINK 值 | 66% |
| `atk` | int | 攻击力。**`-2` 表示 `?`**（不固定数值）；魔法/陷阱为 0 | 60%（非 0 非 -2 者约 9,012） |
| `def` | int/null | 守备力。`-2` 表示 `?`；**连接怪兽为 `null`**（其箭头见 `link_marker`） | 96%（14,513 非空 = 15,019 - 506 连接怪） |
| `lscale` | int | 灵摆**左**刻度。仅灵摆怪兽非 0 | 2%（371 张） |
| `rscale` | int | 灵摆**右**刻度。仅灵摆怪兽非 0 | 2%（371 张） |
| `link_marker` | int | 连接箭头位图原始值（0x01左下 0x02下 0x04右下 0x08左 0x20右 0x40左上 0x80上 0x100右上）。仅连接怪兽非 0 | 3%（506 张） |
| `link_marker_text` | str | 箭头方向中文，`/` 分隔。如"下/右" | 3%（506 张） |

### 全类型通用字段

| 字段 | 类型 | 作用 | 有效占比 |
|---|---|---|---|
| `alias` | int | **马甲指向**。非 0 时表示这张卡"当作"另一张卡（值为那张卡的 `id`）。两种用途：① 同名再版/异画卡指向初版；② 规则上当作另一张卡名的卡（如「传说之都 亚特兰蒂斯」alias=22702055 指向「海」）。检索"是否这张卡"时要把 alias 链一并算上 | 3%（580 张） |
| `setcode` | int | 系列码原始值。可打包多个系列（每 16 位一个，低 12 位是主系列号） | 55%（8,310 张属于某系列） |
| `setname` | str | 系列中文名，可多个用 `/` 分隔。如"次世代/真次世代"。不属于任何系列则为空 | 55% |
| `category` | int | 效果类别位掩码（标记这张卡的效果涉及哪些动作：破坏/检索/特召/回手等），YGOPro2 的"效果类别筛选"就用它。程序上可用于"找有破坏效果的卡"这类查询 | 88%（1,774 张为 0，多为无效果怪兽） |
| `desc` | str | 效果文本/卡描述全文（含换行符）。通常怪兽的 desc 是 flavor 文本 | 99%（仅 2 张衍生物占位为空） |

### 取值要点速记

1. **判卡种**先看 `card_kind`；**判具体形态**（同调/超量/灵摆/连接…）看 `type_text` 里是否含关键词
2. `def == null` ⟺ 连接怪兽；连接的 LINK 值在 `level_decoded`
3. `-2` 是 `?`，`0` 是真 0，两者别混淆
4. 灵摆刻度只有灵摆怪兽非 0，且 `level_decoded` 同时是它的 P 怪兽等级
5. 匹配卡名时除了 `id` 相等，还要考虑 `alias` 指向

## 七、重新导出

```bash
# 全部语言
python export_cards.py

# 指定语言
python export_cards.py zh-CN
```

脚本读 `cdb/<lang>/cards.cdb`，输出到 `export/`。卡池更新后重跑即可。
